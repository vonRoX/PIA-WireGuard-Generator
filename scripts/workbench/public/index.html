Connect your UniFi console

Three steps. Nothing is changed on the console while you set up.

What you enter here stays on this computer.

    Console address

    The address you use to open the UniFi console in a browser on your home network.

    Compare this with the certificate your browser shows at this address. Trust it only if they match.

    In Chrome or Edge, open , click Not secure in the address bar, then Certificate details. Look for the SHA-256 fingerprint. Upper or lower case does not matter.

    A self-signed certificate is normal for a UniFi console. What matters is that this fingerprint is the same one your browser sees.

  2. 2

    UniFi API key

    Create the key on the console itself:

    1. Open https://192.168.1.1 and sign in.
    2. Go to Settings → Control Plane → Integrations.
    3. Create an API key, copy it, and paste it below.

    A key from unifi.ui.com (Site Manager) will not work.

    Site Manager keys are for Ubiquiti's cloud. The console refuses them, so the key has to be created on the console as described above.

    This key is a site-admin credential: it can read your tunnels' private keys. It is checked against the console, then encrypted for this Windows account (DPAPI) and never shown again.

  3. 3

    Private Internet Access login

    Used to get fresh WireGuard keys for your tunnels. It is not checked with PIA yet; a typo shows up the first time keys are refreshed.

    Encrypted for this Windows account (DPAPI) and never shown again.
